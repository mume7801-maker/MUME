# MUME — 家づくりの発信ノート

家づくりで悩んでいる方に向けたInstagramリールの下書き作成アプリです。

## 起動

Node.js 22以上を使用します。外部パッケージのインストールは不要です。

```sh
cd /workspace/MUME
npm test
npm start
```

既定では127.0.0.1:3000にバインドします。必要に応じてPORTとHOSTを設定できます。
`GET /health` が `{"status":"ok","mode":"rules"}` を返すことを確認してください。

## できること

- 参考投稿の文章・文字起こしから冒頭と末尾を抜粋し、特徴的な語句を検出
- 5つの家づくりテーマに対応した30秒・60秒の定型台本とキャプションの生成
- 台本の編集、ブラウザー内への保存（最新30件）、テキストの書き出し

## 現在の範囲

AIサービスは未接続です。入力文章の意味を理解した分析・独自台本生成は行いません。
Instagram URLは参考情報として記録するだけで、投稿を取得しません。
台本の尺は目安です。音読して調整してください。
保存データはブラウザー内にあり、アカウントや端末間同期はありません。
入力は実行中のサーバーへ送信されますが、サーバー側では保存・外部転送しません。
公開運用の認証・アクセス制御は未実装です。
